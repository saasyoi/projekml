Quick Tips
📱

Never Install APK Files from Chat

Legitimate apps are only downloaded from Google Play Store or the App Store. An .apk file sent via WhatsApp is almost always malicious.

🔐

OTP Codes Are Strictly Confidential

Never share an OTP code with anyone — including someone claiming to be a bank officer, police officer, or government official.

🔗

Verify the Link Address

Before clicking, confirm the website address is correct. "mandiri-online.verify.xyz" is very different from "bankmandiri.co.id".

⏰

Urgency Is a Warning Sign

Scammers always create a false sense of urgency. "Your account will be blocked in 30 minutes!" is an intimidation tactic, not a fact.
